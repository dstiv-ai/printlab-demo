# PrintLab3D — classroom demo

[Open the interactive demo](https://dstiv-ai.github.io/printlab-demo/)

An interactive portfolio demonstration of a school 3D-printer queue: sample submissions, teacher approval, simulated printing, material allowances, monitoring and bookings. No sign-in is needed.

All classroom data is fictional. Printer activity and AI monitoring are scripted simulations. The demo has no application backend, live AI calls, uploads or analytics. Changes last only for the current page session.

This repository contains only built static files. The original application source is not published here.

Designed and built by Dimitrios Stivaktas.
